# 🎓 Study HUB - AI Academic Operating System

Study HUB is an all-in-one AI study platform offering PDF/Document RAG query processing, interactive MCQs, smart summaries, mindmaps, flashcards, and student user authentication.

## 🚀 Getting Started

### 1. Prerequisites
- Node.js (v18+)
- MongoDB Atlas cluster or local MongoDB instance

### 2. Installation
```bash
npm install
```

### 3. Environment Setup
Copy `.env.example` to `.env` and fill in your credentials:
```bash
cp .env.example .env
```

### 4. Running the Application
```bash
npm start
```
Access the application at `http://localhost:5000`.
